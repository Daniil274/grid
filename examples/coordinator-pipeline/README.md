# Coordinator Pipeline Example

Пример автономного агентского пайплайна на базе Grid с координатором, который строит конвейеры из динамических агентов через `orchestrate`.

## Идея

**Координатор не делает работу сам.** Он:
1. Декомпозирует задачу
2. Запускает агентов-исследователей (параллельно)
3. Синтезирует спецификацию на основе находок
4. Запускает агента-исполнителя
5. Запускает агента-верификатора
6. Выдаёт пользователю проверенный результат
