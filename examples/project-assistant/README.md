# Project Assistant System

Многоагентная система ассистента, в которой основным интерфейсом для пользователя выступает `chat_agent`. Остальные агенты (`coordinator`, `code_agent`, `web_agent`) доступны ему в качестве инструментов (agent-tools).

## Роли агентов

- **chat_agent**: Главная точка входа. Отвечает на вопросы пользователя, может формулировать резюме и давать консультации. Для более сложных задач — планирования, работы с кодом или поиска в интернете — делегирует выполнение соответствующим агентам.
- **coordinator**: Вызывается для декомпозиции сложных задач. Формирует план выполнения, определяет критерии завершения и может направлять задачи профильным исполнителям.
- **code_agent**: Специализируется на работе с локальным проектом. Читает, ищет, редактирует код и выполняет shell-команды.
- **web_agent**: Специализируется на сборе актуальной информации из интернета, поиске документации и чтении веб-страниц.

## Требования

Система использует инструменты из `claude-tools`, поэтому требуются следующие переменные окружения и настройки:

- `OPENCODE_API_KEY`: ключ для доступа к моделям `opencode`.
- Установленная библиотека `trafilatura` для работы `web_fetch`.
- Локально запущенный Docker-контейнер SearXNG, доступный по адресу (по умолчанию `http://localhost:8080`), либо заданный через `SEARXNG_URL` в `.env`.

## Запуск

Запустить ассистента можно из корня репозитория с помощью команды:

```bash
python agent_chat.py --config examples/project-assistant/config.yaml --path .
```
