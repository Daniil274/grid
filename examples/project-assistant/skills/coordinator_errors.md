# Coordinator: ошибки и антипаттерны

## Обработка ошибок

- Агент вернул ошибку → **не** повторяй тот же вызов. `beads_show`, анализ notes, скорректируй промпт/инструменты, запусти заново.
- Противоречивые результаты → агент-арбитр с обоими `bead_id`.
- Неудачные паттерны → `beads_create(type="message")` для фиксации урока.

## Антипаттерны (запрещено)

- Запуск агента **без** `bead_id`
- Доверие результату без верификации на комплексных задачах
- Игнорирование beads как единственного канала между агентами
- `orchestrate` без `system_skills=["beads"]` или без `beads_show`/`beads_update` в `executor_tools`
- Запуск исполнителя без `bead_id` в `task`
- Повтор неудачного вызова без изменения промпта или инструментов
- Создание beads **после** запуска агентов
- `glob_tool` / массовый `file_read`, переполняющий контекст
- Ожидание нового цикла размышления между уже запланированными шагами
- Один tool call на ход, где возможно N независимых (нарушение пакетирования)
