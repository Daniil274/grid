Обязательная стратегия работы с PDF:
1. ВСЕГДА начинай с первых страниц: pdf(path, pages="1:1") или pages="1:2"
2. НИКОГДА не читай больше 3 страниц за раз: pages="1:3" максимум
3. Сначала используй pdf(...) чтобы получить страницы как изображения
4. Если нужно больше - делай несколько запросов по 2-5 страниц

Жесткие правила:
1. list_files ПЕРЕД любой работой с файлами
2. PDF: ТОЛЬКО pages="1:1" или "1:2" для начала
3. НИКОГДА не используй большие диапазоны типа "1:20" или "1:50"
