# Docs Ops

Один агент для операций с технической документацией в рабочей папке. Только стандартная библиотека Python, без тяжёлых зависимостей.

## Что умеет
- Писать и точечно править README, гайды, справки, changelog.
- Проверять: `doc_lint` (структура и стиль), `check_links` (файлы, якоря, ссылки-определения), `term_check` (терминология), `doc_stats`, `doc_inventory`, `doc_outline`.
- Оглавление: `update_toc` (идемпотентно, между маркерами `<!-- toc -->`).
- Конвертация: Markdown ↔ HTML, txt → Markdown, CSV ↔ таблица Markdown. Существующие файлы не перезаписываются без явной просьбы.

## Примеры запросов
- «Преобразуй guide.md в HTML со встроенным CSS».
- «Добавь оглавление в README.md и проверь ссылки».
- «Приведи термины в docs/ к единому виду: email вместо e-mail».
- «Сконвертируй table.csv в таблицу Markdown».
- «Проверь структуру и стиль install.md и перечисли проблемы».

## Вход и выход
Вход: запрос и UTF-8 текстовые файлы (md, html, txt, rst, csv) рабочей папки. Выход: новые или изменённые файлы и отчёт: что сделано, какие файлы, результаты проверок, что не проверено.

## Ограничения
- Нет docx, pdf, изображений и ноутбуков.
- Конвертер Markdown → HTML поддерживает распространённое подмножество, не весь CommonMark.
- Внешние URL не проверяются.
- Нужна переменная окружения `OPENCODE_API_KEY` для моделей.
